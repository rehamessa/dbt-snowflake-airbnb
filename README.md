# dbt + Snowflake: Airbnb Analytics

An analytics engineering project that transforms raw Airbnb data
(listings, hosts, reviews) into clean, tested, and documented models
using dbt and Snowflake.

## Tech Stack
- **dbt Core** 1.11
- **Snowflake** (cloud data warehouse)
- **Python** 3.13

## Setup
```bash
python -m venv .venv
.venv\Scripts\Activate.ps1      # Windows
pip install -r requirements.txt
```
